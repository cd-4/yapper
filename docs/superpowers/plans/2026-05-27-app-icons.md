# App Icon Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the app icon so it is square, has a purple background, and has rounded corners — then regenerate all platform variants (macOS .icns, Windows .ico, Linux PNGs).

**Architecture:** A Python/Pillow script creates a 1024×1024 source PNG (purple background, white-stripped logo centered, rounded corners). The Tauri CLI's `icon` subcommand then generates all platform variants from that source. `tauri.conf.json` is updated to reference the generated files.

**Tech Stack:** Python 3 + Pillow (already available), Tauri CLI (`npm run tauri`).

### Task 1: Generate 1024×1024 source PNG

**Files:**
- Create: `scripts/gen-icon.py`
- Create: `src-tauri/icons/icon-source-1024.png` (output of the script)

- [ ] **Step 1: Create the generation script**

Create `scripts/gen-icon.py` with this content:

```python
from PIL import Image, ImageDraw
import sys, os

src_path = os.path.join(os.path.dirname(__file__), '..', 'src-tauri', 'icons', 'icon.png')
out_path = os.path.join(os.path.dirname(__file__), '..', 'src-tauri', 'icons', 'icon-source-1024.png')

src = Image.open(src_path).convert('RGBA')

# Remove white background
pixels = list(src.getdata())
clean = [(r, g, b, 0) if r > 240 and g > 240 and b > 240 else (r, g, b, a)
         for r, g, b, a in pixels]
src.putdata(clean)

# 1024x1024 purple canvas (#6f4bd8)
SIZE = 1024
canvas = Image.new('RGBA', (SIZE, SIZE), (111, 75, 216, 255))

# Scale logo to 820x820 box, preserving aspect ratio
BOX = 820
ratio = min(BOX / src.width, BOX / src.height)
logo = src.resize((int(src.width * ratio), int(src.height * ratio)), Image.LANCZOS)

# Center on canvas
x = (SIZE - logo.width) // 2
y = (SIZE - logo.height) // 2
canvas.paste(logo, (x, y), logo)

# Rounded corner mask (radius 180px)
mask = Image.new('L', (SIZE, SIZE), 0)
ImageDraw.Draw(mask).rounded_rectangle([0, 0, SIZE - 1, SIZE - 1], radius=180, fill=255)

result = Image.new('RGBA', (SIZE, SIZE), (0, 0, 0, 0))
result.paste(canvas, mask=mask)

result.save(out_path)
print(f'Saved {out_path}')
```
